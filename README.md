# Saferplast Main

Стартовый каркас проекта под лендинг для пластиковых окон на `Next.js + TypeScript + Tailwind`.

## Корневая структура

- `src/app` — App Router, layout и страницы.
- `src/features/landing` — секции лендинга.
- `src/features/calculator` — калькулятор стоимости.
- `src/features/lead-form` — форма заявки и обработка лида.
- `src/components` — переиспользуемые UI-компоненты.
- `src/lib` — конфиги, утилиты, бизнес-логика.
- `src/types` — общие типы.
- `public` — изображения, иконки, статические файлы.
- `docs` — архитектурные заметки и интеграционные решения.
- `scripts` — вспомогательные скрипты проекта.
