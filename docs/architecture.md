# Архитектура проекта

## Почему `src`

Корень проекта должен оставаться чистым: в нем только конфиги, документация и инфраструктурные файлы.
Весь прикладной код вынесен в `src`, чтобы по мере роста лендинга не смешивать маршруты, UI, бизнес-логику и утилиты.

## Разделение по feature-модулям

- `landing` отвечает за маркетинговые секции.
- `calculator` отвечает за расчет стоимости.
- `lead-form` отвечает за сбор заявок.

Такое разделение проще для поддержки, чем хранить все компоненты в одной плоской папке.

## Cloudflare

Деплой планируется на Cloudflare, но конкретный адаптер лучше фиксировать после выбора точной версии Next.js и способа хостинга:
- Cloudflare Pages
- Workers с OpenNext adapter

Поэтому на этом этапе я не закладываю жесткую build-цепочку, а оставляю проект готовым к подключению выбранного варианта без перестройки структуры.
