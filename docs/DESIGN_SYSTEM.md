## 📝 Типографика

### Шрифты

#### 1. **Montserrat**
- **Использование:** Основной шрифт для интерфейса, текст, кнопки, формы
- **Начертания:**
  - `Regular (400)` - обычный текст, описания
  - `Medium (500)` - кнопки, подзаголовки
  - `SemiBold (600)` - акценты
- **Подключение:** Google Fonts

```css
@import url('https://fonts.googleapis.com/css2?family=Montserrat:wght@400;500;600&display=swap');
```

#### 2. **Sansation**
- **Использование:** Заголовки, цифры, акцентные элементы
- **Начертания:**
  - `Regular (400)` - заголовки разделов, нумерация шагов
- **Подключение:** Google Fonts

```css
@import url('https://fonts.googleapis.com/css2?family=Sansation:wght@400&display=swap');
```

### Размеры шрифтов

| Использование | Размер | Шрифт | Начертание |
|---------------|--------|-------|------------|
| **Главный заголовок** | `55px` | Sansation | Regular |
| **Заголовки разделов** | `44px` | Sansation | Regular |
| **Подзаголовки** | `30px` | Sansation / Montserrat | Regular / Medium |
| **Текст кнопок** | `20px` | Montserrat | Medium |
| **Основной текст** | `16px` | Montserrat | Regular |
| **Номера шагов** | `26px` | Sansation | Regular |

### Примеры применения

```tsx
// Главный заголовок
<h1 className="font-['Sansation'] text-[55px] text-[#004b62]">
  Окна, двери и балконы из ПВХ
</h1>

// Заголовок раздела
<h2 className="font-['Sansation'] text-[44px] text-[#004b62]">
  Почему к нам обращаются
</h2>

// Подзаголовок карточки
<h3 className="font-['Montserrat'] font-medium text-[30px] text-[#004b62]">
  Гарантия 1 год
</h3>

// Кнопка
<button className="font-['Montserrat'] font-medium text-[20px] text-white">
  Бесплатный замер
</button>

// Обычный текст
<p className="font-['Montserrat'] text-[16px] text-[#242424]">
  Описание услуги
</p>
```

## 📐 Отступы и размеры

### Border Radius
- **Малый:** `10px` - поля ввода
- **Средний:** `15px` - кнопки
- **Большой:** `20px` - карточки
- **Очень большой:** `30px` - контейнеры секций

### Gaps
- **Между элементами формы:** `26px`
- **Между чекбоксами:** `15px`
- **Между пунктами меню:** `24px`
- **Между карточками:** `20-30px`

### Shadows
- **Форма заявки:** `0px 0px 16.3px 0px rgba(0, 75, 98, 0.62)`
- **Кнопки категорий:** `0px 0px 19.9px 0px rgba(0, 75, 98, 0.41)`
