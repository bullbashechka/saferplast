# Описание проекта Saferplast

`Saferplast` — это лендинг на `Next.js 15` для компании по окнам, дверям и балконам (ПВХ и алюминий).

## Что делает сайт

- Презентует услуги: изготовление, установка и ремонт.
- Показывает преимущества, процесс работы, проекты, отзывы и FAQ.
- Дает посетителю быстрый путь к заявке через форму и мессенджеры.
- Позволяет получить предварительный расчет через калькулятор.

## Для кого

Сайт ориентирован на клиентов, которым нужны решения для квартиры, дома, офиса или коммерческого объекта.

## Главная цель лендинга

Конвертировать посетителей в обращения: бесплатный замер, консультация и расчет стоимости.
