# Адаптация диапазона 768px-1024px

## Контекст

Задача по адаптации лендинга в диапазоне `768px-1024px` отложена и должна продолжаться уже в текущем стеке:

- `Astro 5`
- `React islands`
- `Tailwind CSS`

Нужно возвращаться к ней без отката к старой SPA-архитектуре.

## Общая цель

Сделать версию лендинга в диапазоне `768px-1024px` визуально близкой к desktop, но:

- без налезания блоков
- без переполнения текста
- без случайного ухода в mobile layout
- без регрессий на wide desktop

Главный принцип:

- не ломать desktop-структуру
- если блоки не помещаются, сначала уменьшать размеры самих блоков, внутренние отступы и кегль
- не переносить решение в breakpoint `<768px`
- не ухудшать поведение на `1280px+`

## Правила для этого диапазона

- Все правки делать только для `768px-1024px`
- Если поведение на `1024px` отличается от `1023px`, значит часть классов слишком рано переключается на desktop breakpoint
- Для проблемных мест лучше поднимать компактный режим выше по breakpoint-логике, если это помогает сохранить структуру
- Если элемент залезает на соседний блок, сначала уменьшать локальные размеры, а не менять глобальную сетку секции

## Что уже всплывало

### Header

- В диапазоне `768px-1024px` пункты меню уезжали в правую колонку hero
- Их нужно держать внутри левой части layout без поломки стандартного desktop header

### HeroSection

- Два мини-блока под заголовком должны оставаться в одну линию
- Эти блоки должны быть одинаковыми по размеру
- Внутри нельзя ломать текст и кнопки
- Если блоки лезут на правую фотографию, нужно уменьшать сами блоки внутри левой колонки

### WorkProcessSection

- В диапазоне `768px-1024px` текст внутри карточек вылезал за границы
- Для этого диапазона нужно уменьшать внутренние размеры карточек, а не менять общую структуру секции

### ProjectsSection

- Сетка должна оставаться desktop-подобной
- При уменьшении ширины экрана должны уменьшаться и сами блоки, и кегль внутри них
- Верхние и нижние линии колонок должны оставаться визуально выровненными

### LeadFormSection

- С `768px` не нужна трёхколоночная декоративная сетка
- В этом диапазоне должна оставаться только центральная форма

## Подход к продолжению

Идти по секциям по очереди:

1. `Header`
2. `HeroSection`
3. `WorkProcessSection`
4. `ProjectsSection`
5. остальные секции, где есть переполнение или налезание

После каждой правки проверять:

- `768px`
- `820px`
- `1024px`
- `1280px`
- `1400px`
