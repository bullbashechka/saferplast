## 2) Стратегия реализации секции

### Компонентная декомпозиция (рекомендуется)
- `src/features/landing/solution-matching-section.tsx` — секция целиком.
- `src/features/landing/solution-matching-content.ts` — типизированный контент/токены (заголовки, тексты, размеры, фоновые слои, ссылки на изображения).
- `src/features/landing/solution-matching-types.ts` — интерфейсы карточек и блока.

### Layout
- Desktop: `3 карточки в первом ряду`, `2 карточки во втором`, с разными размерами верхнего и нижнего рядов.
- Mobile: перестройка в 1 колонку с сохранением порядка и текстовой иерархии; размеры переводятся в адаптивные значения, не в абсолютные координаты макета.

### Фоны/overlay
- Для верхних 3 карточек: фото + white fade overlay (360deg).
- Для нижней 1: двойной overlay (черный 0.2 + white fade).
- Для нижней 2: по текущему контексту использовать аналогичную схему с фото, согласованную в plan/execution с визуальной консистентностью нижнего ряда.

## 3) UX/interaction и доступность

### Поведение CTA
- `Узнать подробнее` для всех карточек ведет на `#lead-form`.
- Рекомендуется единый интерактивный элемент (`<a href="#lead-form">`) с фокус-стилем, чтобы сохранять доступность клавиатурной навигации.

### A11y
- Каждая карточка — отдельный `article` с содержательным alt/aria-подходом.
- Контраст текста поверх фото контролируется overlay + внутренним полупрозрачным контейнером.
- Для screen reader: заголовок карточки как ключевая точка, `Узнать подробнее` — явный action label.

## 4) Риски и меры

### R1: Потеря читаемости текста на фото
- **Риск:** разные фото ухудшают контраст.
- **Мера:** закрепить overlay как обязательный слой и добавить fallback-темнение для конкретных карточек при низком контрасте.

### R2: Несоответствие pixel-perfect из-за абсолютных координат Figma
- **Риск:** попытка буквального копирования `top/left` сломает адаптив.
- **Мера:** использовать relative layout через grid/flex и контролируемые max-width/min-height.

### R3: Поломка порядка FLOW-02
- **Риск:** секция может оказаться не сразу после калькулятора.
- **Мера:** явно зафиксировать в плане изменение порядка в `src/app/page.tsx`.

### R4: Неконсистентный CTA-роутинг
- **Риск:** часть карточек ведет иначе.
- **Мера:** единый source-of-truth для CTA href (`#lead-form`) в content contract.
