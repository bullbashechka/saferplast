## UI: Заголовок, подзаголовок и карточки

| Option | Description | Selected |
|--------|-------------|----------|
| Заголовок/подзаголовок свободные | Типографика определяется на этапе реализации | |
| Заголовок/подзаголовок фиксированные | Точные тексты и типографика из макета | ✓ |
| Карточки в вертикальном desktop layout | Колонки стекуются даже на desktop | |
| Карточки горизонтально на desktop | 4 карточки в один горизонтальный ряд | ✓ |

**Выбор пользователя:** Заголовок и подзаголовок фиксированы по параметрам; 4 карточки (`окно`, `дверь`, `балкон`, `подоконник`) расположены горизонтально на desktop.
**Заметки:** Для карточки утверждён базовый размер `285x210`, radius `20`, padding `40/30`, gradient поверх фото.

## UI: Поведение карточки и CTA

| Option | Description | Selected |
|--------|-------------|----------|
| Статичная карточка | Без hover-эффекта и без дополнительной кнопки | |
| Hover с уменьшением + CTA | Карточка уменьшается, под ней появляется кнопка | ✓ |
| Разный текст кнопки по карточкам | Кнопка зависит от типа категории | |
| Единый текст кнопки | Одинаковый CTA для всех карточек | ✓ |
| Кнопка ведёт к якорю | Скролл к секции/форме | |
| Кнопка открывает модалку | Открытие калькулятора в modal | ✓ |

**Выбор пользователя:** На hover карточка уменьшается до `285x152`, появляется кнопка `286x50` (`hsla(194, 100%, 19%, 1)`), текст кнопки одинаковый `Рассчитать`, кнопка открывает модалку калькулятора.
**Заметки:** В правом нижнем углу карточки должна быть стрелка; при уходе курсора карточка возвращается в исходное состояние.
